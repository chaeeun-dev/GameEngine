[이론]

Interaction: 게임 안에서 발생ㅎ사는 액터 간의 상호작용
- 공질: 야구 피칭 수류탄 투척
- 칼질: 칼 공격, 펀칭
- 총질 -> 너무 빠름. 라인 트레이스로 계산

인터렉션 구현
- 물리 엔진에 위임
	- 편하지만 실행 부하가 매우 큼 -> 꼭 필요할 때만 쓰자
- 직접 개입해서 일일이 처리
	- 바운딩 박스 등을 두어 계산 부하를 줄임

1. 객체(= 컴포넌트)마다 오브젝트 유형을 설정(기본 설정이 되어 있지만 따로 직접 설정해보자)
충돌 단위는 컴포넌트!
- WorldStatic
- WorldDynamic
- Pawn
- PhysicsBody
- Vehicle
- Destructible
2. 객체 별로 충돌 반응과 트레이스 반응을 설정
- Blocking, Overlap, Ignore
- 자기가 상대 컴포넌트의 타입에 따라 어떻게 반응할 것인지에 대해 설정함.
3. 충돌 검사 여부와 수행 방식 설정
- No Collision
- Query Only
- Physics Only
- Collision Enabled
4. Hit 이벤트 및 Overlap 이벤트에 대한 처리

1~3 설정하는 것 너무 번거롭. 사전 프리셋이 있음.
