점프는 스페이스 바를 누를 때만 재생하는 게 아니라, 위에서 아래로 떨어질 때도 재생해야 함
ABP에서 Event Graph에 Is Falling 노드 연결 후 On Air? 변수 Set
GroundMoving to Winging에 On Air? 연결
Winging에 Falling Idle 연결 후 Loop 체크
Wining to GroundMoving은 not On Air?

Ground Moving -> JumpUp 연결
JumpUp State에는 Jump 애니메이션 연결 후 Loop 안 함
JumpUp -> Winging 화살표 안으로 들어가지 말고 Details 창에서 Automatic Rule Based lon Sequence ~ 체크하면 애니메이션 끝나면 자동으로 상태 바꿔줌
Winging -> JumpDown
JumpDown -> GroundMoving도 자동으로 바꿔주기

Jump Up 도약 하는 중간(40%)에 Winging으로 바뀌어야 함
JumpUp to Winging 조건에 time remaining ratio (Jump) - < 0.6 -> result
